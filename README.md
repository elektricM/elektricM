# Martin

Lycéen in France, building things with hardware and code.

I like making devices do things they weren't supposed to do — putting Linux in calculators, teaching cameras to yell at bad posture, that kind of stuff.

## What I'm working on

**[numworks-pi](https://github.com/elektricM/numworks-rpi)** — Raspberry Pi Zero 2W inside a NumWorks calculator. Custom power board, kernel driver, full case mod. Because why not run Linux on your graphing calculator.

**[posture-pilot](https://github.com/elektricM/posture-pilot)** — ESP32 camera that watches your posture. Starts with gentle reminders, escalates to an AIRHORN if you keep slouching. TensorFlow Lite on a microcontroller.

**[AMD BC250 docs](https://github.com/elektricM/amd-bc250-docs)** — Community documentation for a handheld gaming PC. Built from Discord knowledge into proper docs. 55+ stars.

Mostly interested in embedded systems, hardware mods, power electronics, and Linux kernel stuff. Learning PCB design with atopile and on-device ML with TensorFlow Lite.

Currently finishing Terminale and figuring out what's next.
