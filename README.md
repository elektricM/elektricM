## 🔧 Currently Building

**[numworks-pi](https://github.com/elektricM/numworks-rpi)** · Raspberry Pi Zero 2W surgically installed inside a NumWorks calculator  
→ Custom power management PCB · Kernel drivers · Full case modification  
→ Because graphing calculators deserve to run real Linux

**[posture-pilot](https://github.com/elektricM/posture-pilot)** · ESP32-powered posture monitoring with attitude  
→ Computer vision on a microcontroller · TensorFlow Lite quantization  
→ Escalates from gentle nudges to AIRHORN if you ignore it  
→ Your spine will thank me

**[nwpi](https://github.com/elektricM/nwpi)** · Power management module for numworks-pi  
→ Buck-boost converter design · Battery monitoring · Safe shutdown logic

**[amd-bc250-docs](https://github.com/elektricM/amd-bc250-docs)** · Community docs for a handheld gaming PC
