## 🚀 Featured Projects

### [🎮 AMD BC250 Documentation](https://github.com/elektricM/amd-bc250-docs) ![Stars](https://img.shields.io/github/stars/elektricM/amd-bc250-docs?style=social)
Community-driven docs for the AMD BC250 handheld gaming PC. **55+ stars, 10 forks**.  
Built with MkDocs from Discord community knowledge. [**Read the docs →**](https://elektricM.github.io/amd-bc250-docs/)

### [🤖 Posture Pilot](https://github.com/elektricM/posture-pilot)
ESP32 camera that monitors your posture and escalates from gentle reminders to an **AIRHORN** if you keep slouching.  
*TensorFlow Lite · Home Assistant · MQTT · ESP32-CAM*

### [🧮 NumWorks-RPI](https://github.com/elektricM/numworks-rpi)
Raspberry Pi Zero 2W running Linux **inside** a NumWorks graphing calculator.  
Custom power board, kernel driver for the display, complete case mod.  
*Hardware modding · Linux kernel · Embedded systems*

### [⚡ NumWorks Power Board](https://github.com/elektricM/numworks-power-ato)
Custom Li-Ion charger + battery protection + 5V buck-boost converter for the NumWorks-RPI project.  
Designed with **atopile** (code-first PCB design).  
*PCB design · Power electronics · atopile*

### [🎨 Collaborative Pixel Art](https://github.com/elektricM/collaborative-pixel-art)
Real-time collaborative canvas built with WebSockets and Node.js.  
Like r/place, but for your own server.  
*WebSockets · Canvas API · Real-time collaboration*
